Which kinds of task this implement can do. A hitch only accepts the implement when it supports at least one of these types. continuous/cardan: a rate along the path · intermittent: on/off along the path · discrete: actions at points · hitch: only lift and lower.
On: the robot switches each section from the task-map rate under its footprint. Off: sections follow the manual activate_sections variables.

Sections

No sections yet. An implement needs at least one section to work on the task map.

An implement is a list of sections, the parts that are switched on and off (or given a rate) independently, such as nozzles, burners or a probe.

Where a section sits. Each section is positioned relative to the hitch ball: the end of the hitch's lifting arm (hitch position from settings.json, moved back by the hitch's link length). From there an optional section link length moves it further back, and then the section transform T moves it to its origin.

Axes (metres, seen from above): +x is right, +y is forward (driving direction), +z is up. A section at y = -1 works 1 m behind the hitch ball.

Footprint. Around its origin a section covers a rectangle width wide (centred on x), reaching up in front and down behind. The robot checks this rectangle against the task map to decide the section's rate, and the as-applied map records it.

Repeats. A boom of identical nozzles is a single section with repeats = number of nozzles and offset = spacing. Copy i is shifted i × offset along +x and named <id>0, <id>1, … So put T.x at the leftmost copy (the most negative x).
