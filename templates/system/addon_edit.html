Addons are Docker containers managed by ilvo-system-manager through the Redis key system.

  • Start reuses a container with this name and image, or creates one from this configuration (pulling the image when it is not on the robot), then starts it.
  • Stop stops the container; it is kept.
  • Update (↻) stops the container, pulls the image, deletes the container and creates a new one. A locally built image is replaced when the registry has an image with the same name and tag.
  • Configuration changes are only used after the system manager restarts, and only for a new container: restart the manager, then Update.

A wrong image name, or a container with this name that was made from another image, makes the current system manager crash on Start. The form refuses an empty image; check the name and tag before saving.
