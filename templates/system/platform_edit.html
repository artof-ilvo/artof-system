{# Coordinate frame #}

All positions (transform) are in metres in one robot frame, the GPS frame: +x is left, +y is forward, +z is up. T is the position [x, y, z], R the rotation [roll, pitch, yaw] in degrees (usually 0).

The GPS transform places the origin of this frame relative to the antenna position the receiver reports. The robot reference point, the rotation centre, the head and every hitch are then placed relative to that origin.

Implements hang off a hitch: their sections are placed relative to the hitch ball, which is the hitch position moved back by the hitch's link length (see Admin → Implements).

The navigation algorithms the operator can choose. The id selects the algorithm in the robot software; the name is what the operator sees.
